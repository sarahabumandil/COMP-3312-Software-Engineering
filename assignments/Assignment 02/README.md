# Assignment #2 – Software Prototyping Tools and Prototype Design

## Assignment Tasks

### 1. Tool Research (Written Report)

- Introduction to prototyping
- Comparison of at least three software prototyping tools based on:
  - Ease of use
  - Main features
  - Advantages
  - Limitations
  - Prototype screenshots
- Conclusion

---

### 2. Prototype Design

Using one selected prototyping tool:

- Design the main application screens
- Show the application flow
- Produce visual screenshots of the prototype

---

### 3. Video Presentation (5 Minutes)

The presentation includes:

- The selected prototyping tool
- Why the tool was selected
- The application idea
- Demonstration of the prototype
