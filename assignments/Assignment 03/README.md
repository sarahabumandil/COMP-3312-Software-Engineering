
In the previous assignment, you built a low/high-fidelity prototype to explore user interfaces and conceptual workflows. While prototypes are excellent for visual alignment, they lack the rigorous detail required for actual system development.
The objective of this assignment is to translate your visual prototype into a comprehensive, unambiguous Software Requirements Specification (SRS) Document following industry best practices (inspired by the IEEE 830 / ISO/IEC/IEEE 29148 standards). This document will serve as the "single source of truth" for what your system must do.
